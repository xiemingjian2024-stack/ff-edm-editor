# 模板命名与主标题字重调整设计

## 目标

统一信息类模板的运营命名，并将常规标题、对比信息、多卖点信息的楼层主标题改为品牌字体常规字重。

## 变更

- 「标题文本-常规」显示名称改为「常规标题」。
- 「卖点信息」显示名称改为「多卖点信息」。
- 两个模板的导出区域名称同步更新。
- 常规标题、对比信息、多卖点信息的楼层主标题统一使用 `font-weight: 400`。
- 多卖点信息中每个卖点自身的小标题保持现有字重，不在本次范围内。

## 兼容性

模板 ID `title-centered` 与 `selling-points-information` 保持不变，因此已有草稿无需迁移，打开后会自动显示新名称和新字重。

## 验收标准

- 左侧模板库、属性面板、导出清单显示新名称。
- 旧名称不再出现在运行中的界面。
- 三个模板的楼层主标题计算字重均为 400。
- 编辑画布、完整预览和 JPG 导出保持一致。
- 现有草稿、字段和图片数据不受影响。
