# 商品卡图片缩放与移动设计

## 目标

为「N×1 商品卡」和「N×2 商品卡」增加统一的商品图片缩放与位置调整能力。每个商品独立保存图片变换，编辑画布、完整预览和导出结果保持一致。

## 数据结构

在每个 `ProductValue` 中增加三个可选字段：

- `scale`：图片缩放比例，默认 `1`。
- `offsetX`：图片水平偏移，默认 `0`。
- `offsetY`：图片垂直偏移，默认 `0`。

字段保持可选，以兼容已有草稿。读取旧商品数据时，缺失字段使用默认值，不执行批量数据迁移。

## 右侧图片操作

商品编辑器继续复用公共图片操作卡片：

- 上传或粘贴新图片。
- 通过图片直链获取图片。
- 悬停图片预览后调整缩放比例。
- 一键重置为 `100% / X 0 / Y 0`。

图片、缩放和偏移变化都写回当前商品的 `ProductValue`，不会影响其他商品。

从 Shopify 链接重新读取商品时，新图片使用默认缩放和位置，避免沿用旧图片的构图参数。手动上传、粘贴或更换图片时同样重置变换。

## 画布拖动

两个商品卡模板的商品图片区改用公共可编辑图片框架：

- 选中楼层后，可在商品图片区直接拖动图片。
- 拖动只更新当前商品的 `offsetX / offsetY`。
- 完整预览和导出模式不提供拖动事件，但应用已保存的变换。

## 模板差异

- N×1 保持当前透明商品图适配逻辑，图片使用 `contain` 基础构图，背景与卡片背景一致。
- N×2 保持当前 `cover` 基础构图。
- 两个模板都在基础构图之上应用相同的平移与缩放参数。

公共图片框架需要支持 `contain` 和 `cover` 两种适配模式，默认行为保持现有信息和 Banner 模板不变。

## 数据流

1. 右侧商品编辑器或画布拖动产生新的图片变换。
2. 模板通过 `onProductChange(slotId, value)` 上报当前商品。
3. 编辑器 reducer 更新楼层内对应的商品槽位。
4. 画布、预览和导出从同一商品数据读取变换。

## 验收标准

- N×1 和 N×2 的每个商品图片都显示缩放与重置控件。
- 可在画布内直接拖动商品图片。
- 不同商品的缩放与位置互不影响。
- 更换图片或重新读取 Shopify 商品后，变换恢复默认值。
- 旧草稿商品图正常显示，默认比例为 100%、位置居中。
- N×1 保持 `contain`，N×2 保持 `cover`。
- 编辑画布、完整预览和导出使用完全相同的图片变换。
