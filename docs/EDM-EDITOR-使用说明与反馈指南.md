# EDM EDITOR 使用说明与反馈指南

> 当前版本：v0.1.9  
> 更新时间：2026 年 8 月 31 日  
> 适用对象：运营、设计及需要制作或检查 EDM 素材的同事

## 一、工具简介

EDM EDITOR 是一款本地运行的 EDM 与 GIF 素材制作工具。运营可以使用预设模板组合楼层，替换图片和文案，配置商品、链接及颜色，并导出符合投放需求的切图和链接清单。

目前主要支持：

- 使用楼层模板搭建 EDM；
- 制作简单循环 GIF；
- 从 Shopify 商品链接读取商品标题、图片、价格及图库；
- 预览、检查并批量导出切图；
- 通过 `.edm` 文件在同事之间发送和接收 EDM 设计稿；
- 将 GIF 作品引用到 Banner 模板中并随 EDM 一起导出。

## 二、开始使用

### 2.1 安装与启动

#### Windows

1. 解压完整安装包，不要只将 `.exe` 文件单独拖出；
2. 双击 `EDM EDITOR.exe`；
3. 如出现“未知发布者”提示，可点击“更多信息”后继续运行；
4. 如果公司电脑的安全策略直接拦截应用，请联系项目负责人或 IT 协助，不建议自行关闭安全策略。

#### Mac

1. 解压完整安装包；
2. 双击 `EDM EDITOR.app`；
3. 如果提示无法验证开发者，可右键应用并选择“打开”，再确认运行；
4. 如果仍无法启动，请记录系统版本、芯片型号和完整提示截图后反馈。

### 2.2 数据保存说明

- EDM 和 GIF 草稿自动保存在当前电脑本机；
- 工具目前没有账号、云端同步和多人实时协作功能；
- 更换电脑、清理应用数据或重新安装前，建议先发送并保存重要 EDM 的 `.edm` 文件；
- GIF 作品目前没有独立的发送功能，重要 GIF 请同时保留导出的 `.gif` 文件和原始图片；
- 同一份草稿不会自动同步到同事电脑。

## 三、首页与作品管理

首页的“我的作品”分为两个标签：

- **EDM**：查看和管理 EDM 草稿；
- **GIF**：查看和管理 GIF 草稿，作品封面会直接播放动画效果。

作品卡片支持以下操作：

- 点击封面进入编辑；
- 修改作品名称；
- 复制作品；
- 删除作品；
- EDM 作品还可以发送给同事。

首页右上角提供：

- **接收设计稿**：导入同事发送的 `.edm` 文件；
- **新建 GIF**：从 GIF 模板开始创建动画；
- **新建 EDM**：创建新的 EDM 草稿。

## 四、EDM 制作流程

推荐按照以下顺序操作：

1. 新建 EDM，并修改作品名称；
2. 从左侧模板库添加楼层；
3. 在中间画布调整楼层顺序；
4. 选中楼层，在右侧修改文案、图片、商品和样式；
5. 点击“完整预览”检查整体内容；
6. 点击“导出切图”，处理检查结果后下载 ZIP。

### 4.1 编辑界面结构

- **顶部**：返回首页、修改作品名、完整预览、导出切图；
- **左侧**：楼层模板和配色套餐；
- **中间**：EDM 画布，可选择、拖拽排序和缩放查看；
- **右侧**：当前楼层的内容、图片与商品、样式设置。

作品修改后会自动保存到本机，无需手动点击保存。

### 4.2 楼层操作

- 点击左侧模板即可把楼层添加到画布；
- 拖拽画布中的楼层可调整顺序；
- 选中楼层后，按键盘 `Delete` 或 `Backspace` 可删除；
- 在输入框中编辑文字时，删除键只会删除文字，不会误删楼层；
- 使用画布顶部的缩放控件可调整查看比例，缩放不会改变最终导出尺寸。

### 4.3 当前楼层模板

#### HEAD

- 品牌 Logo；
- 分类导航；
- 顶部横幅。

#### Banner

- 常规 Banner；
- 图文 Banner。

这两个 Banner 均可使用静态图片，也可以引用已创建的 GIF 作品。

#### 标题

- 常规标题。

#### 信息

- 单卖点信息；
- 多卖点信息；
- 对比信息；
- CODE。

#### 商品卡

- N×1 商品卡；
- N×2 商品卡；
- N×3 商品卡；
- 产品介绍卡。

#### 页尾

- 页尾保障信息、四个链接、品牌 Logo、三个社媒入口和公司信息。

### 4.4 文案编辑与局部强调

- 在右侧“内容”中直接编辑标题、描述和按钮文案；
- 支持的标题和描述可以开启“强调部分文本”；
- 在文本框中选中文字后，可设置粗体、字号或强调色；
- 按钮、价格和货币字段不提供局部强调，避免样式规则过于复杂。

### 4.5 图片操作

图片通常支持以下方式：

- 选择本地图片上传；
- 粘贴图片或 Shopify 链接后读取；
- 点击“粘贴复制板”读取剪贴板图片；
- 在画布中拖动图片调整位置；
- 使用缩放控件调整图片大小；
- 重新上传或重置图片位置。

建议在导出前检查：

- 主体是否被裁切；
- 四周是否露出底色；
- 图片清晰度是否足够；
- 链接与图片是否对应。

### 4.6 商品卡与 Shopify 自动填充

1. 将 Shopify 商品链接粘贴到对应商品的链接输入框；
2. 点击“自动填充”；
3. 工具会读取商品标题、主图、图库和价格；
4. 可从图库中替换图片，也可手动修改标题、描述和价格；
5. 商品图片可以拖动和缩放；
6. 支持的商品标题、描述可分别设置局部强调。

如果读取失败：

- 先确认商品链接能在浏览器中正常访问；
- 检查当前网络环境；
- 再次点击自动填充；
- 仍失败时可手动上传图片和填写内容。

### 4.7 配色套餐

- 配色套餐用于统一控制楼层间隔背景色和按钮色；
- 可以新建、编辑、复制和删除自定义套餐；
- 单个楼层可覆盖套餐颜色；
- 覆盖后可点击“重新关联”，恢复跟随配色套餐。

## 五、GIF 制作流程

1. 在首页点击“新建 GIF”；
2. 选择模板；
3. 上传图片并调整顺序、位置和大小；
4. 设置每帧时长及模板允许的其他内容；
5. 使用“播放预览”检查循环效果；
6. 点击“导出 GIF”。

### 5.1 4图·宫格高亮轮播

- 固定 4 张图片、4 帧；
- 四张图片按左上、右上、右下、左下依次高亮；
- 未高亮图片自动叠加 40% 蒙层；
- 支持一次选择最多 4 张本地图片；
- 可以拖拽调整图片顺序，并在画布内调整每张图片的位置。

### 5.2 N图·切换轮播

- 支持 2–5 张图片循环播放；
- 默认 2 张，最多 5 张；
- 支持一次选择多张本地图片；
- 可以拖拽调整播放顺序；
- 可分别调整每张图片的大小和位置；
- 画布高度可在模板限定范围内调整。

### 5.3 单图·文字跳动

- 固定 1 张背景图、2 帧；
- 两帧图片和蒙层保持不变，仅文字颜色发生变化；
- 支持眉题、标题、描述和按钮；
- 标题最多 3 行、描述最多 2 行、按钮最多 1 行；
- 描述可选中部分文字作为第二帧强调内容；
- 可分别配置眉题色、标题与描述色、第二帧强调色和按钮色。

### 5.4 4图·左右轮播

- 固定 4 张图片、4 帧；
- 播放顺序为：图片 1＋2 → 图片 3＋2 → 图片 3＋4 → 图片 1＋4；
- 支持一次选择最多 4 张本地图片；
- 可以拖拽更换图片顺序；
- 每张图片可独立调整大小和位置；
- 导出尺寸宽度为 750px，高度可在 375–750px 范围内调整。

### 5.5 在 Banner 中引用 GIF

1. 先在首页创建并保存 GIF 作品；
2. 进入 EDM，添加“常规 Banner”或“图文 Banner”；
3. 在右侧“图片与商品”中点击“引用 GIF 作品”；
4. 在弹窗中浏览并选择 GIF；
5. 如后续修改了源 GIF，可点击“同步最新”；
6. 取消引用后，Banner 会恢复为普通静态图片模式。

注意：GIF 作品不会在编辑后自动同步到已引用的 Banner，需要手动点击“同步最新”。

## 六、预览与导出

### 6.1 完整预览

“完整预览”用于检查整封 EDM 的视觉效果，不会立即生成文件。建议重点检查：

- 楼层顺序；
- 文案是否完整；
- 图片裁切和清晰度；
- 商品标题、价格及链接；
- 背景与按钮颜色；
- GIF 播放是否符合预期。

### 6.2 导出检查

点击“导出切图”后，工具会检查：

- 必填图片是否缺失；
- 商品链接是否缺失；
- 商品图片是否缺失；
- 模板是否可正常导出。

检查结果分为：

- **阻断问题**：必须修复后才能导出，例如必填图片缺失；
- **提醒问题**：可以继续导出，但建议先确认，例如商品链接或商品图片缺失。

### 6.3 ZIP 文件内容

导出的 ZIP 通常包含：

- 各楼层或点击区域的 JPG 切图；
- 引用动画的 Banner GIF；
- `full-preview.jpg`：整封 EDM 长图预览；
- `link-manifest.csv`：切图名称与跳转链接清单。

导出规格：

- 设计画布宽度为 375px；
- JPG 切图按 2× 输出，常规宽度为 750px；
- JPG 图片本身不保存跳转链接，投放时需参考 `link-manifest.csv` 配置。

GIF 最多保存 256 色，照片中可能出现轻微色阶变化，这是 GIF 格式本身的限制。

## 七、发送和接收 EDM 设计稿

### 7.1 发送设计稿

1. 在首页找到需要发送的 EDM；
2. 点击作品右侧的“…”；
3. 选择“发送”；
4. 点击“下载 `.edm` 文件”；
5. 通过飞书把文件发送给同事。

### 7.2 接收设计稿

1. 在首页点击“接收设计稿”；
2. 选择同事发来的 `.edm` 文件；
3. 工具会在本机生成一份新的 EDM 草稿；
4. 打开草稿，检查图片、商品信息和 GIF 引用后再继续编辑。

`.edm` 文件用于传递可继续编辑的设计稿；导出的 ZIP 用于投放，两者用途不同。

## 八、常见问题

### 8.1 草稿突然找不到

- 确认是否使用了同一台电脑；
- 确认是否打开了同一个应用版本；
- 检查是否清理过应用或浏览器站点数据；
- 重要 EDM 建议定期导出 `.edm` 文件备份。

### 8.2 Shopify 自动填充失败

- 确认链接完整且商品页可以正常打开；
- 检查当前网络环境；
- 重试读取；
- 必要时手动填写并上传图片。

### 8.3 GIF 预览正常，但 Banner 中不是最新内容

进入 Banner 的 GIF 引用信息，点击“同步最新”后重新导出。

### 8.4 导出按钮无法点击

查看右侧“检查结果”，先补齐标记为阻断的问题。

### 8.5 切图没有链接

JPG 和 GIF 文件本身不携带跳转链接，请使用 ZIP 中的 `link-manifest.csv` 配置投放链接。

### 8.6 Windows 提示应用可能不安全

当前内部测试包未经过 Microsoft Store 发布。请保留完整提示截图并联系项目负责人或 IT，按公司安全规范处理。

- **P0 紧急**：无法启动、草稿丢失、全部作品无法导出；

## 十、当前能力边界

- 草稿仅保存在本机，没有账号和云端同步；
- 暂不支持多人同时编辑同一草稿；
- GIF 以模板化的简单循环动画为主，不替代专业动画软件；
- Shopify 自动读取依赖当前网络可以访问商品页；
- 导出链接需要通过 `link-manifest.csv` 配置到实际投放平台；
- 当前版本属于内部使用版本，遇到问题请按上述反馈模板提交。
