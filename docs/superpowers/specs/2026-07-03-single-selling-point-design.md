# 单卖点信息模板设计说明

## 目标

在“信息”分组新增“单卖点信息”模板，用于组合楼层标题、描述、单张卖点图片和底部按钮，并保持与“多卖点信息”一致的品牌样式和编辑体验。

## 内容与样式

- 标题、描述、按钮文案、背景颜色、文字颜色、按钮背景颜色和按钮文字颜色沿用“多卖点信息”的默认值、编辑规则及主题色位绑定。
- 描述和按钮允许留空；标题保留。
- 标题区采用与“多卖点信息”一致的字号、字重、行高和上下间距。
- 图片宽度固定为 375px，默认高度为 200px，可在 100–300px 间调整。
- 图片支持上传、从剪贴板粘贴、缩放、拖动位置和重置位置。
- 按钮位于图片下方，与图片间距为 20px，底部边距为 24px。
- 楼层高度随标题、描述、图片高度和按钮显示状态自动变化。

## 数据与导出

- 使用单独的媒体槽位 `feature` 保存图片、缩放和位置。
- 使用 `imageHeight` 字段保存图片高度。
- 整个楼层作为一张 JPG 导出，不拆分标题、图片和按钮。
- 不读取 Shopify 商品信息，不保存图片跳转链接。

## 模板库

- 模板显示在“信息”分组中，位于“对比信息”之后、“多卖点信息”之前。
- 未提供专用缩略图时使用模板库默认占位预览，后续可直接替换为用户提供的 SVG。

## 验证

- 自动测试覆盖模板注册、字段、媒体槽位、图片高度范围、主题色位、按钮可选和完整楼层导出。
- 完整测试、类型检查和生产构建必须通过。
