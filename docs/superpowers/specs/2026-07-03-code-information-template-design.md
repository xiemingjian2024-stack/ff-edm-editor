# CODE 信息模板设计

## 目标

在「信息」分组新增「CODE」模板，用于需要由 EDM 投放平台插入原生优惠码组件的邮件。编辑器展示完整结构供运营预览，但只导出 CODE 组件上方和下方两张 JPG。

## 楼层结构

模板宽度固定为 375px，从上到下包含三个固定区域：

1. 顶部标题区，高度 60px。
2. CODE 占位区，高度 56px。
3. 底部行动区，高度 84px。

楼层总高度固定为 200px。三个区域使用同一个背景色，拼接后不出现色差。

## 顶部标题区

默认文案为 `Copy Your Code`。

- 文案可编辑。
- 固定单行显示。
- 超出可用宽度时使用省略号。
- 字号、字重、对齐和间距固定，不提供调整入口。
- 文字颜色固定为黑色。

## CODE 占位区

编辑画布和完整预览中显示一个固定灰色描边框，用于提示 EDM 平台 CODE 组件的位置。

- 不提供文案或样式编辑入口。
- 不保存优惠码内容。
- 不配置跳转链接。
- 不生成 JPG 切图。

占位框只用于结构预览，不代表最终平台组件样式。

## 底部行动区

底部包含行动文案和说明文案：

- 行动文案默认 `SAVE NOW`，可编辑，固定单行，超出时省略。
- 行动文案左右各有一条水平线，右侧包含固定箭头图形。
- 行动文案、两侧线条和箭头共用一个强调色。
- 强调色可自定义，不绑定主题色位。
- 说明文案默认 `*Selected Summer Cooling Products Only`，可编辑，固定单行，超出时省略。
- 说明文案颜色、字号、字重和位置固定。

## 配色

- 楼层背景色是唯一绑定主题色位的字段，默认绑定主题色位 A。
- 强调色为独立可编辑颜色，默认 `#FFAC33`，不绑定主题色位。
- 顶部标题和底部说明文字颜色固定，不提供编辑字段。

## 属性面板

内容分组只展示三个文本字段：

- 顶部文案。
- 行动文案。
- 说明文案。

颜色分组展示：

- 背景颜色。
- 强调颜色。

CODE 占位区不展示任何配置项。

## 导出规则

模板使用 DOM 区域切图，只导出：

- `CODE 顶部`：375×60px 设计尺寸，导出为 750×120px JPG。
- `CODE 底部`：375×84px 设计尺寸，导出为 750×168px JPG。

中间 56px CODE 占位区不导出，也不生成完整楼层长图。两张切图均不携带链接。

## 验收标准

- 信息分组中可以添加「CODE」模板。
- 三处文案均可编辑并限制为单行省略。
- CODE 占位区可在画布和完整预览中看到，但右侧没有对应配置。
- 背景绑定主题色位 A，强调色不绑定。
- 行动文案、线条和箭头始终使用同一个强调色。
- 只导出顶部和底部两张 JPG，尺寸分别为 750×120px 和 750×168px。
- 中间 CODE 区和完整楼层都不导出。
