# HEAD 分类导航模板设计

## 1. 目标

在 `HEAD` 分类新增“分类导航”模板。运营可配置 2–4 个导航项，每项填写文案和可选链接；导出时按导航项等分切图，并把链接字符写入链接清单。

## 2. 模板尺寸与视觉

- 设计尺寸：375×46px。
- 完整楼层只用于编辑画布和内部切图，不单独导出 JPG。
- 背景默认关联 `主题色位 A`，允许手动覆盖和重新关联。
- 全部导航文字统一使用一个颜色，默认关联 `主题色位 B`，允许手动覆盖和重新关联。
- 品牌字体，字号固定 11px，不开放字号、字重、位置和间距编辑。
- 每个导航项等宽、水平和垂直居中。
- 相邻导航项之间显示固定竖线分隔符。
- 文案最多两行，超出部分省略，不改变楼层高度。

## 3. 导航项配置

- 属性面板提供“导航数量”：2 / 3 / 4。
- 默认 3 项：`Home`、`Carrier & Travel`、`Couch Covers`。
- 属性面板按用户视角将内容成组展示：
  - 导航项 1：文案 + 链接
  - 导航项 2：文案 + 链接
  - 根据当前数量继续显示导航项 3、4
- 链接允许留空，只作为字符串保存，不跳转、不读取页面、不校验网址。
- 从 4 项减少到 2 项时，隐藏项的数据保留；再次增加数量后恢复，避免误删运营输入。

## 4. 数据协议

楼层增加通用导航项数据，每项包含：

- `text`：显示文案。
- `url`：可选链接字符串。

模板声明动态导出区域来源为导航项，并声明“不输出完整楼层图”。区域数量等于当前导航数量，宽度为 `375 ÷ 数量`，最后一个区域吸收小数舍入误差，保证 2 倍切图总宽度严格为 750px 且无缝隙。

该协议不借用商品槽位，后续其他文字导航模板可复用。

## 5. 导出

- 不输出 750×92px 的完整楼层 JPG。
- 当前 2 / 3 / 4 个导航项分别输出 2 / 3 / 4 张等分 JPG。
- 每张切图在链接清单中对应一行，包含导航项文案、切图文件名、区域尺寸和链接字符串。
- 空链接保留为空，不阻止导出。

## 6. 验收

- HEAD 分类出现“分类导航”模板。
- 楼层尺寸、主题色位 A/B、固定字号和分隔线正确。
- 导航数量可在 2 / 3 / 4 间切换并正确等分。
- 文案与链接在同一导航项分组内编辑。
- 隐藏项数据可以恢复。
- 两行溢出省略且楼层不增高。
- 切图数量、宽度、链接清单一一对应。
- 导出 ZIP 中没有该模板的完整楼层 JPG。
- 画布、完整预览与导出结果一致。
