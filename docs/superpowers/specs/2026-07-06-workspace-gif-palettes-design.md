# 工作台、GIF Banner 与配色管理设计

## 作品与导航

顶部返回箭头是编辑器唯一的页面返回入口，左侧竖栏只切换编辑工具。主页统一展示作品，并分为“草稿”和“已导出”两个列表。每个 EDM 只保存最近一次成功导出的冻结快照；草稿和导出快照均可复制为新的草稿。

## GIF Banner

GIF 是 Banner 的动效形态，复用常规 Banner 与图文 Banner 的尺寸和内容规则。EDM 内 Banner 可启用 2–4 帧图片循环；主页也可新建只包含一个 Banner 的 GIF Banner 作品。第一期提供每秒切换、无限循环，以及 CTA“无动画/呼吸缩放”。

## 配色套餐

配色列表允许创建、编辑、复制和删除自定义套餐。表单只包含名称及 A、B、C 三个十六进制色值；经典套餐只读但可复制。
