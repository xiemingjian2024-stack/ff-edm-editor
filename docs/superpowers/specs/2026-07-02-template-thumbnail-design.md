# 左侧模板预览图统一规范

## 目标

简化左侧楼层模板卡片，统一所有模板预览图的视觉尺寸，方便后续由设计师持续提供并替换正式预览图。

## 卡片内容

- 移除左侧模板卡片中的全部“主题色位”标签。
- 每张卡片仅展示：预览图、模板名称、模板实际设计尺寸。
- 配色页与右侧属性面板中的主题色位功能保持不变。

## 预览图规范

- 正式设计稿尺寸：160×90px。
- 比例：16:9。
- 页面中的所有模板预览框使用相同宽高比和相同展示高度。
- 预览图使用居中铺满裁切（`object-fit: cover`），不变形、不留白。
- 当前程序生成的占位预览也放入同一尺寸框中，后续可直接替换为正式图片。

## 响应式展示

左侧模板库继续使用两列布局。预览图在卡片内部按可用宽度等比缩放，设计源文件仍统一使用 160×90px。

## 验收标准

- 左侧楼层模板卡片不再出现“主题色位”文字。
- 所有可见模板预览框尺寸一致，宽高比均为 16:9。
- 模板名称和实际楼层尺寸继续正常展示。
- 搜索、分类和添加模板功能不受影响。
